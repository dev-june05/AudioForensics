# =============================================================================
# Install instructions
# =============================================================================
#
# 1) Confirm torch/CUDA are intact first (see command above).
#
# 2) Install everything EXCEPT torch/torchvision normally:
#      pip install -r requirements-dgx-b200.txt --no-deps
#
#    The --no-deps flag is intentional: several of these packages (opencv-python,
#    scikit-learn, librosa) list "torch" or "numpy" as loose/unpinned deps in
#    their own metadata. Without --no-deps, pip may try to "resolve" a newer
#    torch or a different numpy and silently upgrade something you don't want
#    touched. After the --no-deps install, run step 3 to catch anything missing.
#
# 3) Sanity-check nothing was skipped that you actually need:
#      pip check
#
#    If pip check complains about a genuinely missing package (not torch/numpy),
#    install that one specific package by name, e.g.:
#      pip install <package-name>==<version> --no-deps
#
# 4) ONLY IF `import torchvision` fails (it likely won't, since it's commonly
#    bundled alongside a matching torch install already) — install the exact
#    matching build, pinned to the CUDA 12.8 wheel index, never plain PyPI:
#      pip install torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128 --no-deps
